# Аудит і виправлення іконок

## Знайдені дефекти

- У п’яти SVG телефону контур закінчувався посеред малюнка. Браузер приймав синтаксис, але показував неповну трубку. Відновлено повний контур зі справної польської головної.
- У двох SVG WhatsApp на сторінках послуг був некоректний малюнок. Замінено на контури наявного `img/icons/gold-whatsapp.svg`, зі збереженням розміру та currentColor.
- Відсутніх файлів іконок не знайдено.

- Перевірено всі 69 HTML-сторінок, PL/RU включно з 404.
- 27 SVG-файлів: валідний XML і цілісні посилання на gradients/clipPath.
- 24 inline SVG; усі 6 контурів телефону тепер відповідають повному оригіналу.
- 14 використовуваних файлів іконок/favicon: шляхи існують. Файли іконок webmanifest також існують.

- git diff --check — PASS.
