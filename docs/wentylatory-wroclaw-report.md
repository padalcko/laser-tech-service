## Індексація та AI-ресурси

До `sitemap.xml` додано чотири HTML URL з взаємними мовними альтернативами та `lastmod`; загалом sitemap містить 86 URL. Markdown/llms-ресурси до sitemap не додавалися, відповідно до чинної архітектури.

Чинний генератор `scripts/build-ai-search.py` оновив `llms.txt`, `llms-full.txt`, чотири нові `index.md`, Markdown чотирьох списків, HTML-посилання на Markdown/llms та `_headers` з канонічними HTTP Link і типами ресурсів. Компактний `llms.txt` отримав дві нові польські позиції за наявним принципом індексу; повний ресурс містить обидві мовні версії.

`robots.txt` і `_redirects` залишилися незмінними. Глобальну політику краулерів не змінено. Нових допоміжних «AI SEO» файлів, прихованого контенту чи гарантій AI-цитування не додано. Основні тексти й FAQ доступні в статичному HTML без виконання JavaScript.

## Технічні перевірки

Виконано `python3 scripts/check-cooling-maintenance.py`: перевірки чотирьох сторінок, 12 розміщень адаптивних фото, 12 FAQ-відповідей та 182 локальних посилань пройшли. Перевірено один H1, унікальні title/description, canonical, мовні альтернативи й перемикач, поля JSON-LD, відсутність повторного визначення організації, sitemap, наявність файлів srcset, завантаження зображень та двосторонні тематичні посилання. Довгі абзаци статті та реалізації не дублюються дослівно.

Виконано `python3 scripts/build-ai-search.py --check`: усі 86 HTML-джерел і згенеровані ресурси актуальні; список застарілих файлів порожній. Виконано `python3 scripts/check-ai-search.py`: перевірено 87 HTML-файлів, 86 ресурсів sitemap, 9328 посилань, 219 JSON-LD блоків і 860 перевірок доступу пошукових краулерів; список проблем порожній. Це локальна перевірка JSON та зв'язків, а не сертифікація зовнішнім інструментом Google.

Локальний Netlify Dev сервер обслуговував усі чотири нові HTML URL з HTTP 200. Markdown-ресурси також відповідали HTTP 200 з `Content-Type: text/markdown; charset=utf-8`, `nosniff` та HTTP Link на відповідний HTML canonical. Метадані усіх дванадцяти WebP перевірено; зайвих EXIF/XMP/ICC немає. Фото оглянуто до і після оптимізації.

Браузерна перевірка Chromium через Playwright пройшла у **48 комбінаціях**: чотири нові сторінки та чотири списки на ширинах **320, 375, 390, 768, 1024 та 1440 px**. Усі відповіді були HTTP 200; горизонтального переповнення, виходу H1 за межі екрана, незавантажених нових фото, деформації фото або помилок JavaScript/консолі не виявлено. На мобільних ширинах перевірено відкриття й закриття наявного меню. Знімки mobile/desktop також оглянуто візуально. Перевірки виконувалися з вимкненими зовнішніми тегами Google Tag Manager, щоб не надсилати тестові події в production-аналітику; її працездатність не оцінювалася.

Окремо всі чотири нові сторінки перевірено у Chromium із вимкненим JavaScript на ширині 320 px: H1 і основні абзаци були видимими, контент доступний без виконання скриптів. Візуальні перевірки стосувалися локального Netlify Dev середовища, не production-деплою.

## Межі перевірки

Команди збірки не запускалися: інструкції середовища передбачають автоматичну перевірку платформою після змін. Проєкт використовує статичні HTML-файли і не має package.json або окремого локального build pipeline. Генерація Markdown/llms була оновленням чинних контентних ресурсів, а не запуском збірки сайту.

Production-деплой, перевірку нових production URL, Google Search Console/Rich Results Test, реальну індексацію, AI-цитування й польові Core Web Vitals не виконано. Немає підтвердженої дати публікації або можливості гарантувати результати зовнішніх пошукових систем. Локальні HTTP-перевірки не замінюють перевірку розгорнутого сайту. Зовнішня аналітика не тестувалася функціонально.

Commit, push і окремий ручний production-деплой не виконувалися. Оригінальні вкладення збережено; проміжні конвертації та браузерні знімки не додано до проєкту. На сайті створено лише PL/RU матеріали; українських публічних версій немає.
